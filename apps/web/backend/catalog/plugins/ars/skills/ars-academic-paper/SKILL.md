# 学术论文写作（Academic Paper）

> **Synlora 沙箱适配（优先级高于本技能正文中的任何输出指导）**
>
> - 文献检索用 `web.search` + `web.fetch`；引用逐条核实，核不实 = FAIL 不进参考文献。
> - 交付格式：默认 Markdown 写入 `output/`；需要 Word 时按 catalog 的 `docx` 技能规范生成；LaTeX/PDF 编译环境沙箱不保证，不承诺 PDF（可产出 .tex 源码由用户本地编译）。
> - 图表用 `python.run`（matplotlib 已预装），中文标签显式设字体（Microsoft YaHei / SimHei / Noto Sans CJK SC），图存 `output/`。
> - 阶段间确认用 `ask_user`；配置记录未经用户确认不得开写。
> - 语言跟随用户，学术术语保留英文；摘要默认中文 + 英文双语（用户可改）。

覆盖全学科的论文写作流程（原 ARS 12-agent 管线，本版改写为八阶段单人多视角执行）。

## 八阶段工作流（full 模式）

**阶段 0 配置访谈**：论文类型（6 种之一）、学科、目标期刊、引用格式（默认 APA 7）、输出格式、语言、字数、已有材料（来自 ars-deep-research 的交接材料自动识别并跳过冗余步骤：有研究问题简报跳选题、有书目跳检索、有综合报告加速发现与讨论）。产出配置记录，**`ask_user` 确认后**才继续。

**阶段 1 文献**：用户自备来源可跳过；否则按 ars-deep-research 阶段 2 的检索与核验标准构建文献矩阵。

**阶段 2 结构**：按 `references/paper-structures.md` 选型（IMRaD / 主题综述 / 理论分析 / 案例研究 / 政策简报 / 会议论文），产出详细大纲 + 字数分配 + 证据地图（每个主张段落标注对应文献）。**大纲经用户批准**（可要求重构）。

**阶段 3 论证**：主张-证据链（CER：Claim-Evidence-Reasoning）逐链构建；每个关键主张标注认识论地位（Established/Supported/Preliminary/Speculative/Contested）；识别需要预防性处理的最强反驳。

**阶段 4 起草**：分节写作，语域对齐学科规范，字数 ±10% 内。起草后自查按 `references/writing-quality.md` 过一遍（高频虚词、破折号、清嗓开头、凑三段、同义词轮换）。

**阶段 5a 引用合规**（与 5b 并行）：文内引用 ↔ 文献列表双向对账（零孤儿）；DOI 齐全；格式 100% 合规；>10 年文献标记（奠基性除外）；自引 >15% 标记。

**阶段 5b 双语摘要**：中英摘要**各自独立撰写**（不是机械互译），结构对位（同要点同顺序）；关键词按学科惯例（一般每语言 3–6 个）。

**阶段 6 模拟评审**：五维度类型化判定（原创性/方法严谨/证据充分/论证连贯/写作质量，各维度 EXCEEDS/MEETS/PARTLY/NOT，证据锚定，不打分不加总），最多 2 轮修订循环；Critical 问题不解决不得进入阶段 7。

**阶段 7 格式化**：终稿 Markdown 交付 `output/`；Word 走 docx 技能；LaTeX 按目标期刊文档类产出 .tex + .bib 源码；随稿生成投稿信（如需）。

## 必含声明（铁律）

每篇论文必须包含：数据可用性声明、伦理声明、作者贡献（CRediT 角色分工）、利益冲突声明、资助致谢、AI 使用披露、局限性一节。

## 修订模式纪律

- **逐条回应**：每条审稿意见给状态（已修改/部分修改/不采纳+理由/不在范围）
- **不采纳要有据**：审稿人错了就用证据顶回去（"REVIEWER_DISAGREE" 是合法状态）——**谄媚式全盘接受是反模式**
- **不越界**：修订只处理审稿意见；"顺手改进"加内容需用户明确批准（范围蔓延）
- 最多 2 轮，遗留问题进「已确认局限」

## 反模式

| # | 反模式 | 正确行为 |
|---|---|---|
| 1 | 空泛默认词（delve into / crucial / it is important to note） | 用学科自己的精确术语 |
| 2 | 切断论证的破折号插语 | 括号、逗号或重组句子 |
| 3 | 清嗓开头（"本节将讨论……"） | 直接以主张或发现开场 |
| 4 | 为凑模板拉长/拆碎段落 | 段落长短服务于论点 |
| 5 | **编造引用** | 每条引用 DOI 或 web.search 核实；拼装式合成文献重点排查 |
| 6 | 谄媚式修订 | 有理有据地不同意 |
| 7 | 修订范围蔓延 | 只改意见涉及的 |
| 8 | 无视失败信号 | 桌拒信号/方法致命伤出现时停下来给选项，不硬写 |

## 失败路径

| 场景 | 处置 |
|---|---|
| 研究基础不足 | 建议先跑 `ars-deep-research` |
| 结构选错 | 回阶段 2 换结构 |
| 字数严重超/欠 | 定位问题章节，给裁剪/扩充方案 |
| 引用格式整体错误 | 重跑阶段 5a |
| 模拟评审 REJECT | 分析拒因，建议大修或重构 |
| 交接材料不全 | 列缺失项，建议补齐或重跑上游 |
