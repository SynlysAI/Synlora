# 论文结构模板（6 种）

## 选型表

| 论文特征 | 用结构 |
|---|---|
| 有原创数据采集与分析 | IMRaD |
| 综合既有文献 | 主题文献综述 |
| 发展/批评/扩展理论框架 | 理论分析 |
| 深析特定机构/项目/事件 | 案例研究 |
| 面向决策者的循证建议 | 政策简报 |
| 学术会议投稿 | 会议论文 |

## 1. IMRaD（实证研究）

适用：理工/社科/教育/医学原创数据研究。典型 5,000–8,000 字。

```
1 标题页
2 摘要 + 关键词
3 引言：3.1 背景语境 / 3.2 问题陈述 / 3.3 研究缺口 / 3.4 目的与研究问题 / 3.5 意义
4 文献综述：4.1 理论框架 / 4.2-4.4 主题块（按主题分块的相关研究）/ 4.5 小结与概念框架
5 方法：5.1 研究设计 / 5.2 对象或样本 / 5.3 数据采集 / 5.4 工具与测量 / 5.5 数据分析 / 5.6 效度与信度 / 5.7 伦理考量
6 结果：6.1 描述统计（如有）/ 6.2+ 逐发现呈现（与 RQ 一一对应）
7 讨论：7.1 发现小结 / 7.2 与文献对话 / 7.3 理论启示 / 7.4 实践启示 / 7.5 局限 / 7.6 未来方向
8 结论
9 参考文献
10 附录（如有）
```

字数分配（6000 字例）：引言 15% / 文献 25% / 方法 15% / 结果 20% / 讨论 20% / 结论 5%。

## 2. 主题文献综述

适用：综合现有研究、识别缺口、提出议程。典型 6,000–10,000 字。

```
1 标题页  2 摘要+关键词
3 引言：3.1 主题与理据 / 3.2 范围与边界 / 3.3 综述方法（检索式、纳入标准）/ 3.4 组织方式
4-6 主题 1-3：每主题下分子主题，主题末小结
7 跨主题综合：7.1 收敛发现 / 7.2 分歧与争论 / 7.3 方法学观察
8 缺口与未来方向：8.1 已识别缺口 / 8.2 研究议程
9 结论：9.1 要点 / 9.2 对实践与政策的启示
10 参考文献
```

字数分配（8000 字例）：引言 10% / 各主题 20%×3 / 综合 15% / 缺口 10% / 结论 5%。

## 3. 理论分析

适用：发展、批评或扩展理论框架。典型 5,000–8,000 字。

```
1 标题页  2 摘要+关键词
3 引言：3.1 理论问题 / 3.2 该理论为何重要 / 3.3 目的与贡献
4 背景：4.1 起源与发展 / 4.2 核心概念与定义 / 4.3 现状
5 批判分析：5.1 框架优势 / 5.2 局限与缺口 / 5.3 竞争视角 / 5.4 经验支撑（或其缺失）
6 提出的扩展/修正：6.1 新维度或修改 / 6.2 概念模型 / 6.3 可检验命题
7 应用与启示：7.1 理论 / 7.2 实践 / 7.3 方法
8 结论：8.1 贡献小结 / 8.2 分析局限 / 8.3 未来方向
9 参考文献
```

字数分配（6000 字例）：引言 12% / 背景 20% / 批判分析 28% / 扩展 20% / 应用 15% / 结论 5%。

## 4. 案例研究

适用：特定机构/项目/事件的深描分析。典型 4,000–7,000 字。

```
1 标题页  2 摘要+关键词
3 引言：3.1 背景与理据 / 3.2 案例选择理由 / 3.3 研究问题
4 文献语境：4.1 相关理论框架 / 4.2 类似案例的已有研究
5 案例描述：5.1 情境与场域 / 5.2 关键行动者 / 5.3 事件时间线 / 5.4 数据来源
6 分析：6.1 分析框架 / 6.2+ 主题/发现
7 讨论：7.1 跨主题综合 / 7.2 与文献比较 / 7.3 理论洞见 / 7.4 可迁移性（不是可概化性）
8 经验教训与建议（实践者/政策/研究者分列）
9 结论  10 参考文献  11 附录（案例文档、数据）
```

字数分配（5000 字例）：引言 12% / 文献 15% / 案例描述 20% / 分析 25% / 讨论 18% / 建议 7% / 结论 3%。

## 5. 政策简报

适用：面向决策者的循证建议。典型 2,000–4,000 字。

```
1 标题与作者
2 执行摘要（200-300 词）+ 核心建议（3-5 条）
3 背景：3.1 政策问题 / 3.2 政策现状 / 3.3 为何现在必须行动
4 证据基础：4.1-4.3 关键发现（必要时含国际比较）
5 政策选项分析：每个选项给 描述/利/弊/成本/可行性
6 建议：6.1 推荐选项及理据 / 6.2 实施步骤 / 6.3 时间线 / 6.4 成功度量
7 结论  8 参考文献  9 附录：方法说明
```

字数分配（3000 字例）：执行摘要 10% / 背景 15% / 证据 30% / 选项 25% / 建议 15% / 结论 5%。

## 6. 会议论文

适用：会议投稿（进行中或已完成研究）。典型 2,000–5,000 字。

```
1 标题、作者、单位  2 摘要+关键词
3 引言：3.1 问题与动机 / 3.2 研究问题
4 相关工作：4.1 关键先行研究 / 4.2 本文所补缺口
5 方法：5.1 设计 / 5.2 数据或材料 / 5.3 分析
6 结果（初步或完整）：6.1 关键发现 / 6.2 表图
7 讨论：7.1 解释 / 7.2 局限
8 结论与未来工作  9 参考文献
```

字数分配（3000 字例）：引言 15% / 相关工作 20% / 方法 20% / 结果 25% / 讨论 12% / 结论 8%。
