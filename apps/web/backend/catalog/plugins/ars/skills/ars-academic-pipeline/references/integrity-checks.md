# 诚信检查协议（两道闸门 + 七类 AI 失效模式）

## 阶段 2.5：稿前诚信检查

范围与判定：

| 相 | 范围 | 手段 |
|---|---|---|
| A 文献核真 | 全部参考文献 | 逐条存在性 + 书目准确性 + 幽灵引用（文内引了列表没有 / 列表有文内没引）。标题+作者+年份 web.search 独立命中；DOI 对得上作品 |
| B 引文语境抽查 | ≥30% 引用语境 | web.fetch 读原文（摘要/正文），核实转述的主张真的在文献里 |
| C 统计/数据面 | 全部统计表述 | 数字前后一致（正文 vs 表格）、分母自洽（N 与自由度对得上）、百分比加总合理 |
| D 原创性抽查 | ≥30% 段落 | 与已发表文献的表述重合检查（可疑句 web.search）；自查自抄袭（与作者已发表工作的重复度与是否标注） |
| E 主张核验 | 高影响主张全量 | 头条结论/数字主张/因果主张/方法关键/有争议的主张逐条核：主张是否被所引证据支撑、是否需要降格措辞（认识论地位） |

FAIL → 逐项修正 → 复查修正项；3 轮仍 FAIL → 列出不可核实项交用户显式决定（记录理由）。

## 阶段 4.5：定稿终检

全部范围提到 100%（含修订新增的文献/段落/主张），并且**从头重查**——不复用 2.5 结论（修订会引入新问题，只查旧问题是反模式）。附加：与 2.5 结果比对，确认此前问题全部解决。PASS（零未决项）才进定稿；3 轮后仍有未决项 → 用户显式决定并记录，永不静默丢弃。

## 七类 AI 研究失效模式清单（两道闸门都要过）

来源：Lu et al. (2026) 对端到端 AI 科研系统失败模式的归纳。这些失效危险在于**看起来都像合格的工作**——含捏造实验结果的论文读起来与真结果的论文一模一样。每类给三态判定：CLEAR（有证据排除）/ SUSPECTED（侦测问题命中）/ INSUFFICIENT EVIDENCE（缺用户输入无法判定）。

**1. 实现缺陷通过自审**：代码有 bug（差一错误、错变量、静默除零）产出数值貌似合理的结果。侦测：每个数字结果有没有对应的已保存运行记录？效应量是否可疑地整（恰好 0.5、恰好 2 倍基线）？误差棒跨条件是否可疑地一致？

**2. 幻觉引用**：不存在的文献、错配的年份/期刊/作者、被安了它没有的发现。侦测：五查逐条核（见 ars-deep-research 的 references/evidence-and-sources.md）。

**3. 幻觉实验结果**：写了"提升 12%"但没有任何一次运行产生过 12%。侦测："X% 改善"类主张有没有原始数字可指？稿中表格对得上已保存的输出文件吗？"跑了 N 个种子"与实际运行目录数一致吗？

**4. 捷径依赖**：结果真实但靠虚假特征而非预期泛化达成（看背景色不看数字形状的 MNIST 模型）。侦测：有没有排除最显然捷径特征的消融？消融消的是声称机制还是无关超参？基线强到必须靠所提机制才能超越吗？

**5. 缺陷被包装成洞见**：意外结果实为 bug，叙事阶段把它重构成"新发现"。侦测：文中"出人意料地/反直觉地/与假设相反"处，有没有文献预测过相反结果（没有文献说相反 = "意外"可能只是 bug）？意外结果首跑就出现还是调试多轮后才出现（后者高风险）？在干净环境从头复现过吗？

**6. 方法捏造**：方法节描述的实验/超参/数据集/流程并非实际所跑，而是"合理版本"的想象。侦测：方法节每个数字（学习率/批大小/轮数/数据规模/划分）在实际运行配置里找得到吗？描述的预处理步骤能指到代码吗？实际没跑的步骤是否用了过去时？

**7. 早期框架锁定**：早期错commit（问题框架/方法选择）后续阶段结构上无法回头，最终论文执行良好但答非所问。侦测：带着现在的认知回到阶段 1，用户还会选这个问题和方法吗？讨论节有"in hindsight / 我们后来意识到"类表述吗（框架锁定信号）？贡献是被所选框架解释得更好，还是无视它也能成立？

**阻断规则**：任一模式 SUSPECTED，或模式 1/3/5/6 为 INSUFFICIENT EVIDENCE（这四类必须有用户提供的运行记录才能排除）→ 阻断流水线，用户三选一：确认回修 / 有据推翻（记录理由） / 修订该段后复查。模式 2/4/7 证据不足可带警示放行，4.5 复查。

> 纯理论或质性论文：模式 1/3/4/6 的多数侦测问题不适用，按论文类型跳过不适用的模式，不硬凑判定。

## 引用幻觉五型（模式 2 的细分）

1. 完全捏造（文献不存在）
2. 拼装造假（2–3 篇真文献的元素拼成一条——最难察觉，逐字段核对作者-年份-期刊搭配）
3. 错误归属（文献真实但被安了它不含的发现）
4. 书目错误（文献真实但年份/期刊/作者写错）
5. 幽灵引用（列表里有、文中没引；或反之）
