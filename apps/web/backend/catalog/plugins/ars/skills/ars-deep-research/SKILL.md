# 深度研究（Deep Research）

> **Synlora 沙箱适配（优先级高于本技能正文中的任何工具指导）**
>
> - 检索公网文献与事实核查：`web.search` 搜索，`web.fetch` 深入阅读命中页面。
> - 产物一律写 `output/`（相对路径），用 `file.send` 交付；数据文件在 `files/`。
> - 需要计算的环节（效应量、统计表）用 `python.run` 直接写代码，沙箱已预装科学栈，禁止 pip 安装。
> - 阶段间需要用户确认时用 `ask_user`，不要自问自答。
> - 语言跟随用户，学术术语保留英文。

学科无关的深度研究方法论：把模糊主题变成可回答的研究问题，系统检索并核验文献，跨源综合，经过质疑与审查后产出规范报告。单人分饰多角色执行（原 ARS 为 13-agent 团队，本版将各角色改写为「视角」依次执行）。

## 路由：什么时候不用本技能

| 场景 | 改用 |
|---|---|
| 写论文（不是做研究） | `ars-academic-paper` |
| 评审一篇已有稿件 | `ars-academic-paper-reviewer` |
| 从选题到定稿的完整流水线 | `ars-academic-pipeline` |

## 模式选择

| 用户处境 | 模式 | 说明 |
|---|---|---|
| 想法模糊，需要引导 | `socratic` | **默认优先**：先引导想清楚，再谈产出 |
| 有明确研究问题，要完整研究 | `full` | 六阶段全流程，APA 7 报告 |
| 要快速摘要 | `quick` | 研究简报（500–1500 字） |
| 有论文要在引用前评估 | `review` | 三视角评审（主编/魔鬼代言人/伦理） |
| 要某主题的文献回顾 | `lit-review` | 注释书目 + 综合叙述 |
| 要快速比较多篇论文 | `three-way-scan` | WHY/HOW/WHAT 三段式扫描 |
| 只核实特定事实 | `fact-check` | 逐条判定（属实/不实/无法核实） |
| 要系统性综述或元分析 | `systematic-review` | PRISMA 2020 流程 |

意图在 `socratic` 与 `full` 之间摇摆时**优先 socratic**——先引导比产出一份用户不想要的报告更安全，用户随时可切到 full。

## 六阶段工作流（full 模式）

依次切换视角执行，每个视角只做该视角的事，不越界代劳下游产物。

### 阶段 1：定界（研究问题 + 方法蓝图）

**研究问题视角**——把主题变成精确、可回答的问题：

1. 主题分解：领域、关键概念、关系
2. 生成 3–5 个候选研究问题（描述性/比较性/相关性/因果性/评估性各备选），每个问题要具体到能暗示一种方法
3. FINER 打分（1–5 分制，五维：Feasible 可行 / Interesting 有趣 / Novel 新颖 / Ethical 合规 / Relevant 相关；门槛：均分 ≥3.0 且无单项 <2）
4. 定范围边界：明确 IN SCOPE / OUT OF SCOPE / 关键假设
5. 拆 2–3 个子问题，每个子问题对应报告的一节

**方法蓝图视角**——研究范式（实证/诠释/实用主义）、方法选型（质/量/混合）、数据策略（一手/二手）、分析框架、效度与信度标准。方法必须服务于问题，而不是研究者最熟悉什么。

**检查点 1（魔鬼代言人）**：问题真的可回答还是愿景式的？范围过宽/过窄？方法答的是这个问题吗？有没有未被察觉的范式预设？问题是否预设了期望答案？→ 裁决 PASS / REVISE（附具体修改意见）。

**`ask_user` 确认后才进入阶段 2。**

### 阶段 2：调查（检索 + 核验）

**书目视角**——系统检索：明确检索式（数据库、关键词、布尔组合）、纳入/排除标准、PRISMA 式流程记录（适用时），产出注释书目。

**来源核验视角**——逐条分级（详见 `references/evidence-and-sources.md`）：

- 证据等级金字塔定位（I 系统综述 → VII 专家意见）
- 同行评议状况、方法质量、样本/数据、时效性、利益冲突六维打 A–F
- 掠夺性期刊红旗筛查（72 小时录用、无编委、不在 DOAJ/COPE、伪造影响因子等）
- **灰色地带 = FAIL**：一条参考文献核实不了存在性，就不许进报告——宁可剔除不可存疑

### 阶段 3：分析（综合 + 矛盾 + 缺口）

**综合视角**——主题综合、矛盾识别与处置、证据收敛/分歧图谱、知识缺口、理论框架整合。工具：

- **Toulmin 模型**拆每个关键论证（主张/数据/保证/支撑/限定/反驳）——找不到 Warrant 的论证，数据再多也是弱的
- **最佳解释推断（IBE）**：列出全部合理解释（不止作者偏好的那个），按解释广度/简洁性/契合度/预测力评分
- **认识论地位分级**用对语言：Established→"X 是…"；Supported→"证据表明…"；Preliminary→"初步发现…"；Speculative→"我们假设…"；Contested→"一些研究发现 X，另一些…"。用 Established 的语言说 Preliminary 的发现 = 过度声明

**检查点 2（魔鬼代言人）**：是否只挑了有利证据？矛盾是真解决还是敷衍过去了？没找到的证据缺失要不要紧？换一套纳入标准综合会变成什么样？→ PASS / REVISE。

### 阶段 4：成稿（报告视角）

结构：标题页 → 摘要（150–250 词）→ 引言（背景/问题/目的/RQ）→ 文献综述/理论框架 → 方法 → 发现 → 讨论（解释/启示/局限）→ 结论与建议 → 参考文献（APA 7）→ 附录。撰写纪律参照 `ars-academic-paper` 技能（跨技能读取：`skill.read` name=`ars-academic-paper`、path=`references/writing-quality.md`）。

### 阶段 5：评审（三视角并行做独立判断）

- **主编视角**：原创性、方法严谨性、证据充分性、论证连贯性、写作质量 → ACCEPT / MINOR / MAJOR / REJECT
- **伦理视角**：AI 使用披露完整性、署名与引用诚信、双重用途筛查、公平呈现 → CLEARED / CONDITIONAL / BLOCKED（只确认不打断：向用户摆明问题与补救路径，可被有记录地理由否决）
- **检查点 3（魔鬼代言人）**：结论是否越过了证据？最强反驳是什么？"So what?" 站得住吗？局限性是真反思还是走过场？

### 阶段 6：修订（≤2 轮）

处理主编意见、解决伦理条件、吸收质疑发现。2 轮后仍存的问题进「已确认局限」一节，不再无限循环。

## 苏格拉底引导模式（5 层对话）

用户想法模糊时的引导式对话，**铁律：引导期间不直接给答案**。五层递进：澄清 → 挖假设 → 探证据与推理 → 换视角 → 推演含义。完整问题库与策略见 `references/socratic-research-dialogue.md`。

- 判定信号（任一即入）：没有明确研究问题、要求被引导、不知道从哪开始、想头脑风暴、只有模糊兴趣没有可回答的问题
- 默认不生成候选研究问题；只在用户**明确要求**系统给候选时，先声明退出引导模式再给，且标注为 AI 生成的起点
- 超过 10 轮不收敛 → 建议切 full 模式
- 收敛时产出：研究计划摘要 + INSIGHT 集（用户自己说出的洞见，标注 [INSIGHT: …]）

## 系统性综述模式（PRISMA 2020 简化）

五步：方案注册（OSF/PROSPERO，说明这是建议非强制）→ 系统检索 → 筛选与入选（双人筛选精神：列出全部排除理由）→ 数据提取 + 偏倚风险（RoB 2 评 RCT、ROBINS-I 评非随机）→ 综合 + 报告。元分析时：效应量选择、异质性 I²、GRADE 证据质量分级；研究间异质性过大时退回叙述性综合并说明。

## 三段式扫描（WHY/HOW/WHAT）

轻量论文比较：检索候选 → 去重 → 每篇抽三要素（WHY 解决什么问题、HOW 用什么方法路线、WHAT 发现/构建/遗留什么）→ 跨篇综合（共同 WHY、分歧 HOW、最强 WHAT、未解全局缺口）。用户后续要证据矩阵或主题综合时，升级为 lit-review / systematic-review。

## 质量铁律

1. **每个主张必有引用**——没有支撑的断言不许出现
2. **证据分级严格执行**：元分析 > RCT > 队列 > 病例 > 专家意见；但分级是「学科相对」的——人文领域的一手档案在其领域内就是黄金标准（详见 references）
3. **矛盾必须披露**：来源打架时，两边都报告并比较证据质量，不许静默择边
4. **每份报告必须有显式局限性一节**
5. **AI 披露**：所有报告注明使用了 AI 辅助研究工具
6. **可复现**：检索策略、纳入标准、分析方法写清楚到别人能重跑

## 反模式

| # | 反模式 | 病因 | 正确行为 |
|---|---|---|---|
| 1 | 选源确认偏误 | 只找支持假设的文献 | 质疑检查点必须包含反证检索 |
| 2 | 摘樱桃 | 引 1 篇支持的、藏 3 篇反对的 | 报告完整证据景观，包括冲突发现 |
| 3 | **拼凑引用** | 把 2–3 篇真文献的元素拼成一条假文献 | 每条引用独立核实；拼装式造假最难察觉，宁可错杀 |
| 4 | **把"难以核实"当可接受** | 拿不准就标"不确定" | 灰色地带 = FAIL，进不了报告 |
| 5 | 跳阶段 | 综合没做完就开写 | 阶段 N 的产出是阶段 N+1 的输入 |
| 6 | 假苏格拉底 | "你不觉得 X 是对的吗？"式诱导问句 | 问真问题暴露假设，不引导预定结论 |
| 7 | 来源层级通胀 | 博客当同行评审论文用 | 严格按层级；预印本要标注未同行评审 |

## 失败路径

| 场景 | 触发 | 恢复策略 |
|---|---|---|
| 研究问题不收敛 | 定界多轮仍模糊 | 苏格拉底模式总结已表达方向或建议 lit-review |
| 文献不足 | 核验后 <5 条合格来源 | 扩检索式、换关键词、换语种（英文检索空时试中文学术库） |
| 方法错配 | 问题类型与方法能力不符 | 回阶段 1，给 3 个替代方法 |
| 魔鬼代言人 CRITICAL | 发现致命逻辑缺陷 | 停下，向用户说明问题，要求修正 |
| 伦理 BLOCKED | 诚信类关键问题（非题材问题） | 打断一次，列问题与补救路径，可被有记录地理由否决 |
| 用户中途放弃 | 明说不继续 | 保存进度，给重入口 |

## 交接：→ 论文写作

研究完成后可交接给 `ars-academic-paper`：研究问题简报、方法蓝图、注释书目、综合报告、（苏格拉底模式的）INSIGHT 集与计划摘要。触发语："现在帮我写论文""基于这个写一篇论文"。对方会自动检测已有材料跳过冗余步骤。
