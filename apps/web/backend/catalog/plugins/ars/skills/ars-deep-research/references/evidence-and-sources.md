# 证据分级与来源核验标尺

## 证据金字塔（7 级）

```
I    系统综述 / 元分析          （PROSPERO 预注册、多库检索、显式纳入排除、PRISMA 报告）
II   随机对照试验（RCT）        （随机分组、对照、盲法、意向性分析）
III  非随机对照研究             （准实验：DID、倾向得分匹配、断点回归）
IV   队列 / 病例对照研究        （观察性，纵向或回顾，不能确证因果）
V    描述性/质性研究的系统综述  （元综合、元民族志）
VI   单项描述性 / 质性研究      （个案、民族志、调查；深度换广度）
VII  专家意见 / 委员会报告      （权威 ≠ 证据）
```

各级注意事项：I 受"垃圾进垃圾出"制约且可能过时；II 在社科/教育常不可行且外推受限；III 有选择偏误风险；IV 有回忆偏误与混杂；VI 不可做因果声明。

## 六维分级标尺（每维 A–F）

| 维度 | A | B | C | D | F |
|---|---|---|---|---|---|
| 证据等级 | 达到/超过本领域该主张的黄金标准 | 低一级 | 低两级 | 远低于领域规范 | 无法分类或根本不适配该主张 |
| 同行评审 | 严格评审 | 标准评审 | 编辑评审 | 无正式评审 | 自发表 |
| 方法 | 典范可复现 | 健全已描述 | 尚可 | 可疑 | 缺失/有缺陷 |
| 样本/数据 | 大且有代表性 | 充分 | 有限但有正当理由 | 小且便利 | 未说明 |
| 时效 | <3 年 | 3–5 年 | 5–10 年 | >10 年 | 对该主题已过时 |
| 利益冲突 | 无或已声明 | 轻微已披露 | 中等已披露 | 未披露的潜在冲突 | 明确未披露冲突 |

**时效是主张相对的**：奠基性/历史性文献不因年代受罚——主张本身关乎该文献或其年代时，不用年龄带。

**分级是学科相对的**：人文领域的一手档案在设计层级上是 VI，但作为该领域诠释性主张的黄金标准，证据等级维可以拿 A。黄金标准参照：医学 I–II；教育 III–IV；社科 III–V；政策 IV+VII；人文 VI；技术 III+行业报告。

### 聚合规则

1. **诚信地板**：利益冲突 F，或（同行评审为本领域规范的领域）评审 F → 总评封顶 D，其余再强也不救
2. **基准分**：六维中位数（A=4…F=0，相邻两档打平时向下取）
3. **契合调整**：证据等级（契合度）为 A 时基准分升一档（不超过 A）；方法为 F 时不适用本条

**总评含义**：A 首要证据 / B 支持性证据 / C 显式告诫后可用 / D 无更好来源才用且承认弱点 / F 不用（仅批判性引用时引）。

## 掠夺性期刊红旗清单

- 72 小时内录用；主动群发约稿邮件
- 无可查证的编委会（或伪造名单）
- 不被 Scopus / Web of Science / PubMed 收录；不在 DOAJ；非 COPE 成员
- 期刊范围大而无当（"国际万事学报"）
- 伪造或虚高影响因子；网站语法拼写粗糙
- APC 异常低（全文 OA 不足 $200）；编辑部地址与注册地不符
- 无撤稿政策或伦理准则

核验入口：DOAJ（白名单）、COPE 成员目录、Scopus Source List、Think. Check. Submit.（thinkchecksubmit.org）。

## 引用真实性五查（每条参考文献必做）

1. 标题 + 第一作者 + 年份在 `web.search` 能独立命中
2. DOI（如有）指向同一作品
3. 期刊真实存在且可检索到该卷期
4. 文内转述的主张确实出现在该文献中（web.fetch 读摘要/正文核对）
5. 多篇文献拼装出的一条"合成文献"= 最严重的造假形态，重点排查作者-年份-期刊的搭配是否在每一处都对得上

灰色地带一律 FAIL：核实不了存在性的引用，进不了报告。
