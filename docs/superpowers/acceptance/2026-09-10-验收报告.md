## 已知限制清单（记录，不扩 V1 范围）

1. **os.system 不拦截**：`python.run` 实际保护边界 = 解释器 `-I` 隔离 + 环境变量白名单
   （PATH/HOME 等 8 项）+ cwd 锁定用户工作区 + 60s 超时 + 64KB 输出截断，
   **不含系统调用拦截**（`-I` 不禁 `os.system`，子进程经 cmd 正常执行）。
   设计文档"受限子进程"口径中的"被拒"应修正为上述实际边界；系统调用级拦截留待
   后续版本（容器 / seccomp）评估。
2. **output/ 产物无前端浏览器**：python.run 产物（如 `output/dist.png`）只能落盘到用户
   工作区 `output/`，右栏文件面板仅展示上传文件（`files/`），前端无工作区文件树/产物
   预览。当前靠助手回复文字说明产物位置 + 后端文件系统验证；V1 验收按此口径通过。
3. **token 用量不显示**：harness 已产出 Usage（prompt/completion tokens），但未透传到
   前端；右栏"运行信息"仅含事件数/轮次/中止数/按工具统计。
4. **验收环境偏差**：mock LLM 端口 9999 → 9998（9999 被本机无关服务占用）；
   本机另遗留多个前端 dev server IPv6 监听（5173-5177，前次开发会话残留），不影响功能。
