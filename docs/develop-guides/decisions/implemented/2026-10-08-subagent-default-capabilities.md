# 子智能体默认能力按职责收敛

状态：implemented
类型：bug-fix
Owner：backend/package/yuxi/agents/buildin/subagent/context.py

## 问题

未显式配置资源的子智能体继承主智能体工具与共享 Skill 的动态全选默认值。新增内置 Skill 会自动进入通用、网页检索、调研及核查子智能体的候选范围，与角色职责不符。既有预置角色的数据库配置只在首次创建时写入，修改预置定义本身不能修正已落库的省略字段。

## 决策

### 实现方案

子智能体 Context 的工具与共享 Skill 默认为空列表，主智能体默认值不变。预置角色在各自模块声明职责所需能力：网页检索与事实核查选择网页搜索工具；调研探索选择网页搜索和知识库 Skill；通用任务不预选专用能力；谱图、高分子和 Sciverse 专家维持专用 Skill 与预加载设置。网页搜索未配置时由既有资源选项过滤，个人 Skill 仍按用户身份可用。

预置子智能体初始化在已存在的数据库配置中只补齐预置定义明确声明且当前缺失的 `tools`、`skills` 字段，主智能体配置保持原样。显式 `all`、空数组、固定列表和其他自定义字段保持原样。repository 提交新增字段，运行准备继续使用既有授权和 Skill 依赖解析。

## 替代方案

统一修改 BaseContext 会影响主智能体；只改预置定义不能修正已有数据库；覆盖整个 context 会抹掉管理员选择；把知识库工具直接放进基础工具列表会绕开 Skill 激活边界。

## 后果

新建子智能体不自动获得后续新增的共享 Skill 或本地工具；专家角色仍可显式预加载专用 Skill。已有预置角色省略能力字段时在初始化时补齐，显式配置不受影响。个人 Skill 独立于共享选项，不能通过该默认值禁用。网页检索依赖部署的搜索供应商。
