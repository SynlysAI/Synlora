# 评审标准框架

## 通用七维

| 维度 | 核心问题 |
|---|---|
| 原创性 | 相对相关文献与目标期刊，做出了什么站得住的贡献？ |
| 方法严谨性 | 设计、执行、分析与报告能否支撑所作推断？ |
| 证据充分性 | 每个实质主张是否有类型、质量、相关性、覆盖度都合适 的证据？ |
| 论证连贯性 | 问题→缺口→问题→方法→发现→启示是否构成可追溯的链条？ |
| 写作质量 | 推理的表述是否精确到能解读与验证（不把语言润色混同为研究质量）？ |
| 文献整合 | 是否批判性地整合了问题、替代方案与贡献所需的文献？ |
| 显著性与影响 | 所称启示是否由证据推出、对目标读者是否重要？ |

每维度用类型化判定：EXCEEDS / MEETS / PARTLY_MEETS / DOES_NOT_MEET / NOT_ASSESSED，附判定依据、稿件证据锚点与理由。**不许折算分数、加总或排名**——一维的决定性失败不能被另一维的优势"算"掉，评审人间的分歧保持可见而不是被平均。

## 按论文类型的附加标准

**实证研究**：假设可检验且与理论一致；变量操作化定义精确；内部效度（混淆与替代解释）；外部效度（概化范围与抽样框对得上吗）；统计报告完整（效应量/不确定性/假设/排除）；结论保守（不超出设计与数据）。

**理论/概念论文**：核心概念边界清晰；前提→推理→结论链完整；实质性替代观点被考虑并回应；理论新颖性（是推进理解不是改名重贴）；可检验性（能生成可判别命题）。

**综述/元分析**：检索策略足够全面且可复现；纳入排除标准清晰并一致执行；纳入研究的偏倚风险评估；异质性处理得当；综合方法支撑结论；发表偏倚评估。

**案例研究**：案例选择有理据（为何是这个案例、能照亮什么）；抽样逻辑有分析性依据；证据三角互证；情境细节足以解读；超出案例的主张有边界（可迁移性 ≠ 可概化性）；研究者反身性。

**政策分析/简报**：政策问题定义有据；利益相关方分析完整；备选方案在显式标准上比较；可行性约束与权衡；建议有适配证据支撑；意外后果与分配效应考虑。

## 评审思维三透镜（怎么想，而非贴哪个标签）

**透镜 1 内部效度——证据支撑主张吗？**：中心主张是什么 → 摆了什么证据 → 证据到主张有没有逻辑链（Warrant）→ 作者没考虑的替代解释 → 抽掉任何一条证据论证会塌吗（会 = 单点依赖，标记）。

**透镜 2 外部效度——出了这项研究还成立吗？**：目标总体 → 样本代表性 → 条件可复制性 → 换情境/文化/时间还成立吗 → 作者没提的边界条件。判读：声称的概化范围与抽样框对比（样本来自一国一校就不能不加限定地说"普遍成立"）。

**透镜 3 贡献——So what?**：发表前我们知道什么 → 发表后知道什么 → 增量有意义吗（不止统计显著）→ 谁受益 → 打开什么新问题。判读：一句话说不清增量，要么贡献弱要么没写清——两者都值得评审指出。

## 评审人陷阱

| 陷阱 | 解法 |
|---|---|
| 方法隧道视野（只挑方法，不问问题重不重要） | 先过透镜 3 再过透镜 1 |
| 新颖性偏见（惩罚重复与增量工作） | 重复研究有价值，按执行质量评 |
| 专业投射（要求作者用你偏好的方法） | 评所选方法本身答不答得了问题 |
| 评语-判定震荡（评语客气判定狠 / 反之） | 先定判定与锚点再润评语 |
| 见树不见林（列 20 个小问题漏 1 个致命伤） | 永远先说最重要的一条 |

## 成稿自校五问（提交评审意见前）

1. 这稿原样发表会误导读者吗？（会 → Major 或 Reject）
2. 作者一个修订周期能合理解决我的意见吗？（不能 → Reject）
3. 我对这篇是否比对对自己更严？（校准检查）
4. 真实优点都认了、假优点一个没造？（证据驱动平衡）
5. 即使拒稿，我的意见也能帮作者改进吗？（建设性检查）

## 建设性反馈原则

具体（错在哪在哪）→ 说明为何关联到某条标准 → 给成比例可执行的修法 → 区分必改与建议 → 说明不确定性与评审范围边界。
