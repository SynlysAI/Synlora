# 论证评估框架与谬误目录

## Toulmin 论证六件套

每个研究论证拆六件，缺件即红旗：

| 组件 | 问什么 | 缺失红旗 |
|---|---|---|
| 主张 Claim | 断言了什么 | 论点模糊或漂移 |
| 数据 Data | 什么证据支撑 | 无经验支撑的断言 |
| 保证 Warrant | 证据为何支持主张 | 数据与结论间逻辑断层 |
| 支撑 Backing | 什么支撑保证本身 | 方法效度被默认 |
| 限定 Qualifier | 确定性多大 | 绝对化语言（"证明""总是"） |
| 反驳 Rebuttal | 什么会推翻主张 | 无已承认的局限 |

判读：**找不到 Warrant，论证就是弱的——再多数据也只是信息，不是论证。**

## 因果推理（Bradford Hill 九条，改编）

论文声称 X 导致 Y 时逐条核：关联强度、一致性（跨研究/情境重复）、特异性（X 专导致 Y 而非一切）、时间顺序（X 先于 Y，**唯一必要条件**）、剂量梯度（X 越多 Y 越多）、机制合理性、与既有知识连贯、实验证据、类比。多数社科论文满足 3–5 条；少于 3 条，因果主张不成立。

## 最佳解释推断（IBE）

同一发现存在多个解释时：列**全部**合理解释（不止作者偏好的），按解释广度 / 简洁性（特设假设少）/ 契合度 / 预测力四维评估。只考虑一种解释 = 确认偏误，无论论证多漂亮。讨论部分至少要处理两个最强的替代解释。

## 认识论地位分级

| 地位 | 含义 | 得体语言 |
|---|---|---|
| Established | 已重复、已评审、高共识 | "X 是…" |
| Supported | 有证据未重复 | "证据表明…" |
| Preliminary | 单一研究/小样本 | "初步发现提示…" |
| Speculative | 推理而无直接证据 | "我们假设…" |
| Contested | 证据冲突 | "一些研究发现 X，另一些…" |

用 Established 的语言说 Preliminary 的发现 = 过度声明，学术写作最常见质量问题。

## 谬误目录（32 条，按族分组）

**形式谬误**：肯定后件（Q 真推 P 真——Q 可有多因）；否定前件；中项不周延；假两难（"要么全线上要么全传统"）。

**关联性谬误**：诉诸人身（评方法不评出身，但利益冲突要记）；诉诸权威（"Nature 发的就是对的"）；诉诸传统；诉诸新颖；诉诸大众；转移话题（红鲱鱼）。

**证据谬误**：摘樱桃（引 5 篇支持、漏 12 篇反对）；确认偏误（检索式偏向有利结果——查检索策略是否中立）；幸存者偏差（"顶尖大学都做了 X"——做了 X 没变顶尖的呢？）；轶事证据；草率概化（三个案例推全部）。

**因果谬误**：先后即因果；相关即因果；反向因果（设施好吸引学生 vs 学费造就设施）；生态谬误（群体层面规律套个体）；辛普森悖论（分组趋势与合并趋势相反——永远并看分组数据）。

**推理谬误**：稻草人；移动球门（结果出来后改成功标准——查标准是否事前定义）；滑坡；循环论证；没有真正的苏格兰人；歧义（"质量"一会儿指标合规一会儿满意度）。

**统计谬误**：基率忽视（90% 满意率 vs 全体基线 88%）；均值回归（最低分组自然回升——有对照组吗）；德州神枪手（跑 20 个检验只报显著的那 1 个——预注册了吗、多重比较校正了吗）；赌徒谬误；麦克纳马拉谬误（只看可量化指标）；古德哈特定律（指标成为目标就不再是好指标）。

## 快速侦测问题表

| 问这句 | 查的是 |
|---|---|
| "B 还有没有别的成因？" | 先后即因果、假因果 |
| "失败的那些呢？" | 幸存者偏差 |
| "样本有代表性吗？" | 草率概化 |
| "标准是结果出来前定的吗？" | 移动球门、德州神枪手 |
| "关键术语前后一致吗？" | 歧义 |
| "基率是多少？" | 基率忽视 |
| "漏掉了什么证据？" | 摘樱桃、确认偏误 |
| "这是对方真实的论证吗？" | 稻草人 |
| "相关和因果区分开了吗？" | 相关即因果、生态谬误 |
| "个体和群体层面混了吗？" | 生态谬误、辛普森悖论 |
