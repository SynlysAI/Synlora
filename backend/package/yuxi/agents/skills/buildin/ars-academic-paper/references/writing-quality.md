# 写作质量诊断清单

**边界**：本清单提升写作质量，不是"去 AI 味"工具，不以骗过检测器为目标。优先级排序：作者要求与目标期刊规则 > 学科惯例 > 已批准的风格样例 > 本清单。以下都是"值得停下来问一句"的判断提示，不是词汇禁令、标点配额或段落模板；只在确有清晰度/精确度/支撑问题时才改，不授权重写本来就健全的文句。

## A. 高频虚词警示

遇到下列词问一句："这是不是这里最精确的说法？"——是就保留。

| 词 | 为什么警示 | 备选（视语境） |
|---|---|---|
| delve / delve into | 过度使用的"探究" | examine, investigate, analyze |
| tapestry | 复杂性的陈腐比喻 | network, interplay, system |
| landscape（非字面） | 模糊 | field, domain, state of |
| pivotal / crucial | 重要性通胀 | important, significant, central |
| foster | 动词模糊 | promote, develop, encourage |
| showcase | 非学术语域 | demonstrate, illustrate, present |
| testament | 陈腐 | evidence, indicator |
| leverage | 商业行话 | use, employ, apply |
| realm | 古雅 | domain, field, area |
| embark | 小题大做 | begin, undertake |
| underscore | 过度强调 | emphasize, highlight |
| multifaceted / nuanced / intricate | 空泛复杂性 | complex, detailed, qualified |
| comprehensive | 常无凭据 | thorough, extensive |
| robust（非统计） | 模糊质量声明 | reliable, rigorous（统计里 robust estimator 是术语，保留） |
| cornerstone | 陈腐比喻 | foundation, basis |
| paradigm（非科学哲学） | 过度使用 | framework, model, approach |
| synergy / holistic / streamline | 行话/无定义 | 具体化 |
| cutting-edge / groundbreaking | 通胀 | recent, novel, pioneering |

## B. 标点模式

- **破折号插入语**：插入成分是澄清论证还是打断论证？打断就换逗号/括号/拆句。
- **分号连句**：两个分句关系紧密且易读才用；过载就拆成两句。
- **冒号列表串**：连续列表是在呈现可比项还是在碎片化论证？该成文的并成文。

## C. 清嗓开头

| 删掉或替换 | 处理 |
|---|---|
| "In the realm of…" | 删，直接以主语开头 |
| "It's important to note that…" | 删——真重要，内容自己会说 |
| "In today's rapidly evolving…" | 删，时间戳式陈词没有信息量 |
| "This serves as a testament to…" | 直接说 "This demonstrates…" 或摆证据 |
| "In order to…" | 改 "To…" |
| "When it comes to…" | 直接上主语 |
| "本节将讨论……"/"The following paragraph examines…" | 直接讨论/检验它 |

例外：引言里的路线图句（"第 2 节综述文献；第 3 节介绍方法"）是标准学术惯例，保留。

## D. 结构模式警告

- **凑三强迫症**：每个论证恰好三个子点、每个列表恰好三项——真实分析不会都分解成三；两个硬观点好过三个注水的。
- **段落长短**：段落空间服务于论点本身；不为模板拉长、不为"看起来有变化"拆碎。
- **同义词轮换**：同一概念一段里换着叫（students→learners→participants→subjects）在学术写作里是缺陷不是文采——术语一致是美德；换词只发生在两个术语真指不同物时。
- **二元对立滥用**：对比是否真有依据，还是在强加假两难。
- **镜像结构**：每节内部结构完全同构（主题句+三证据+小结）——方法节可以程序化、讨论节可以探索式，结构跟着内容需要走。

## E. 句长与可读性

句长匹配含义：短句可以强调发现，长句可以解释关系；难读的段落检查句子结构是否是病因，但长度相似本身不是缺陷。摘要服从期刊的结构与字数要求。

## 使用方式

起草后自查（首选）或终稿通读（兜底）时过一遍；确认的问题在授权范围内修，实质性的证据缺口与未满足的期刊要求单独报告；一遍修完的问题不做重复美容。
